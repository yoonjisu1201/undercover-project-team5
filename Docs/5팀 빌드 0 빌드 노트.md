## 3. 플레이에 필요한 정보

### 기본 조작
1. **WASD** → 이동
2. **Shift (누르고 있기)** → 달리기
3. **마우스 이동** → 시점(화면) 회전

### 주의사항
- 1인칭 시점 카메라만 구현되어 있습니다.

### 현재 플레이 가능한 범위
> 플레이어 이동 → 달리기 → 마우스로 시점 회전 확인
