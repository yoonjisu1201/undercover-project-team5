## 1. 한 줄 요약

**본부와 현장으로 역할이 나뉜 팀이, 군중 속에 위장한 외계인을 제한시간 안에 식별·포획하는 협동 추리 파티 게임.**

- 플레이 인원: **3~4인**
- 핵심 구조: **본부(관제) ↔ 현장(조사)** 역할 분담
- 승리 조건: 제한시간 내 외계인 후보 확정 → 포획 성공
- 한 판 길이(목표): **15~20분** 라운드

플레이는 `초기 단서 수신 → 현장 조사 미션 → 본부 힌트 전달 → 후보 탐색 → 방해 대응 → 포획 후보 확정 → 포획` 순으로 이어진다. 제한된 단서에서 출발해 조사로 힌트를 열고, 말 전달의 혼선과 방해를 넘기며 외계인을 찾아내는 것이 핵심이다.

## 3. 기획 의도 & 핵심 경험

이 게임은 **본부가 관제 화면과 힌트를 보고 설명**하고, **현장이 군중 속 외계인 후보를 직접 확인**하는 정보 비대칭 구조에서 출발한다.

- **본부**는 초기 단서와 새로 열린 힌트를 보고 현장에 **말로 전달**한다.
- **현장**은 군중 속 후보의 외형·행동·주변 단서를 **직접 확인**한다.
- 두 역할이 서로의 설명을 대조하며 **후보를 줄여 나간다**.

라운드 초반에는 외계인을 바로 특정하기 어려운 **초기 단서만** 제공된다. 현장요원이 조사 미션으로 추가 힌트를 열면, 본부가 새 힌트를 말로 설명한다. 힌트는 애매한 그림, 도형, 부분 이미지, 짧은 영상처럼 **해석이 갈릴 수 있는 형태**로 제공되어, 되묻고 확인하는 대화를 자연스럽게 만든다.

수색 도중 동선 막힘·시야 차단·장비 오류·본부 화면 지연 같은 **방해**가 짧게 발생해 흐름을 끊는다. **외계인 콘셉트**는 무전 교란·UFO 납치·중력 이상·이름표 교란 같은 비현실적 방해를 세계관 안에서 자연스럽게 납득시키는 장치다.

## 4. 핵심 차별점

| 차별점 | 설명 |
| --- | --- |
| **본부가 탐색을 이끈다** | 본부는 CCTV·현장 요원 위치·추가/갱신 힌트를 보고 현장의 이동 방향을 안내한다. |
| **힌트는 후보를 줄이는 단서다** | 힌트는 여러 후보에 동시에 해당될 수 있다. 본부 설명 + 현장 확인을 합쳐 가능성 낮은 후보를 제외한다. |
| **수색을 방해하는 요소** | 현장·본부에 짧은 방해가 발생해 수색을 잠시 어렵게 만든다. |

## 5. 레퍼런스

정보 전달 · 조사 누적 · 짧은 방해 · 수습 대화가 어떻게 플레이로 이어지는지를 중심으로 차용한다.

| 레퍼런스 | 차용 요소와 적용 |
| --- | --- |
| **Keep Talking and Nobody Explodes** | 본부가 힌트 원본을 보고 말로 설명, 현장은 듣고 후보를 찾는다. 말 전달의 답답함·혼선을 참고. |
| **Phasmophobia** | 현장 조사로 증거를 모아 후보를 좁히는 흐름. 조사 성공 → 힌트 도착 → 후보 축소 순서로 적용. |
| **Lethal Company** | 협동 탐사 중 돌발 상황을 말로 수습하는 순간. 공포 강도는 낮추고 짧은 방해·확인 대화에 사용. |
| **Escape Simulator** | 공간을 뒤져 단서를 찾는 감각. 물건 조사·흔적 채집·단말 복구·시민 탐문 미션에 연결. |
| **Overcooked** | 맵 변화·동선 압박 속 역할 분담. 경로 막힘·조명 꺼짐·시야 차단·장비 위치 변경으로 적용. |
| **PEAK** | 작은 방해가 이동·합류를 어렵게 하고 서로 도와 복구. 드론 납치·점액 구속·외계 벌레 등으로 적용. |

## 6. 타겟 재미(Core Pillars)

1. **말로 설명하는 과정의 혼선** — 애매한 힌트를 본부가 말로 풀고, 현장이 실제 후보와 대조. 같은 단서도 다르게 받아들여 되묻는 대화가 발생한다.
2. **후보가 좁혀지는 과정** — 초기 단서는 후보를 넓게 남기고, 조사로 열린 힌트가 후보를 하나씩 제외하는 근거가 된다. 점점 확신에 가까워진다.
3. **짧은 방해를 수습하는 협동** — 이동 방해·시야 차단·장비 오류가 짧게 발생. 팀은 위치를 다시 공유하고 도움을 요청하며 수색을 이어간다.
4. **포획 성공의 팀 성취감** — 본부 설명·현장 관찰·추가 힌트 확인이 맞물린 결과로 포획이 이뤄져, 함께 판단해 잡았다는 성취감이 남는다.

## 7. 게임 흐름(Game Loop)

```
① 초기 단서 수신   본부가 흐릿한 몽타주·일부 외형·색 조각·도형 등 제한 단서를 확인 → 현장에 말로 전달
② 초기 후보 탐색   현장이 설명을 듣고 군중 속 넓은 후보군 구성
③ 현장 조사 미션   현장이 군중·물건·흔적·장소를 조사하거나 짧은 미션 수행
④ 본부에 힌트 도착  미션 성공 시 본부 화면에 새 힌트 등장
⑤ 본부의 말 전달   본부가 새 힌트를 설명 → 현장이 후보를 다시 좁힘
⑥ 혼선과 재확인    표현 차이가 생기면 외형·위치·행동을 다시 대조
⑦ 방해 대응        방해 발생 시 위치·후보 상태·필요한 도움을 짧게 공유
⑧ 후보 축소        확인 정보 + 새 힌트로 가능성 낮은 후보 제외
⑨ 포획 후보 확정   단서가 충분히 쌓이면 본부·현장이 포획 대상 결정
⑩ 포획            현장이 확정 후보를 제한시간 안에 포획 → 라운드 승리
```

핵심 순환 고리: **조사(현장) → 힌트 해금 → 전달·혼선(본부↔현장) → 후보 축소 → (방해) → 재확인** 을 반복하며 확신에 도달한다.

## 8. 역할 설계

### 8.1 본부 (관제)

- 초기 단서와 조사로 열린 힌트를 현장에 **말로 전달**한다.
- 힌트 원본(그림·도형·부분 이미지)을 직접 보고 말로 풀어 설명한다.
- 각 현장요원의 진행 중인 조사 미션을 파악하고, 새 힌트가 뜨면 팀에 공유한다.
- 갱신 힌트·CCTV·현장 공유 정보를 종합해 후보 위치를 추정하고 수색 방향을 안내한다.
- **포획 후보를 확정**하고 판단 근거를 현장에 공유한다.
- 방해 발생 시 CCTV 채널·지도 방향·무전 표시를 다시 확인하고, 현장에 상황 공유를 요청한다.

### 8.2 현장 (조사·포획)

- 초기 단서와 본부 설명을 바탕으로 **외계인 후보군을 구성**한다.
- 군중·물건·흔적·장소를 조사해 **추가 힌트를 여는 미션**을 수행한다.
- 힌트가 애매하면 후보의 외형·행동·소지품을 다시 확인해 본부에 공유한다.
- 본부가 후보를 확정하면 **현장에서 포획을 실행**한다.
- 길 막힘·조명 꺼짐·시민 무리·UFO 납치·점액 구속 등 방해 발생 시 상황과 필요한 도움을 공유하고, 가까운 요원이 지원한다.

## 9. 핵심 시스템

### 9.1 초기 단서와 힌트 해금

힌트는 처음부터 완성된 형태로 주어지지 않는다. 라운드 초반에는 **초기 단서만** 주어지고, 조사 미션을 완료할 때마다 본부에 새 힌트가 도착한다.

- **초기 단서**: 흐릿한 정면 몽타주, 일부 외형, 색 조각, 도형, 짧은 목격 증언 → 넓은 후보군만 형성.
- **조사 미션**: 떨어진 물건 조사, 시민 탐문, 장비 스캔, 흔적 채집, 단말 복구 등 짧은 미션.
- **본부 힌트 도착**: 미션 성공 시 이미지·도형·짧은 영상·부분 확대 컷·소리 단서 등 새 힌트 등장.
- **말 전달과 혼선**: 본부가 힌트를 직접 보고 말로 설명 → 현장이 듣고 확인 → 표현이 엇갈리면 되묻는다.
- **단서 구체화**: 초반 단서는 후보를 넓게, 이후 복장·소지품·행동·이동 방향 힌트로 좁힌다.
- **힌트 형태**: 흐릿한 몽타주, 색 조각, 도형(삼각형/원형), 행동 그림, 부분 이미지(가방끈·소매 끝), 금속성 소리 등 **말로 옮기기 애매한** 단서로 구성.

### 9.2 후보 탐색과 확정

- **초기 후보군 만들기**: 초기 단서 + 본부 설명으로 넓은 후보군 형성.
- **조사 미션 분담**: 현장요원이 서로 다른 대상을 나눠 조사해 추가 힌트를 연다.
- **힌트 해석과 필터링**: 본부 설명을 현장이 확인하며 가능성 낮은 후보 제외.
- **방해 이후 확인**: 방해 시 이동·구조·장비 복구를 먼저 처리, 후보를 놓치면 마지막 위치·이동 방향을 공유해 수색 지속.
- **포획 후보 확정**: 초기 단서 + 조사 힌트가 충분히 쌓이면 포획 후보 결정.

### 9.3 포획 판단과 실행

- 본부는 확인된 힌트 + 현장 확인 내용으로 포획 가능성을 판단한다.
- 현장은 판단 근거를 바탕으로 실제 후보의 외형·행동을 최종 확인한다.
- 팀은 제한시간 안에서 **더 조사할지 / 지금 포획할지** 선택한다. (판단 압박)
- 제한시간 내 포획 성공 시 **라운드 승리**.

### 9.4 외계인 방해 이벤트

> **기준**: 방해는 포획을 피하려는 외계인의 교란과 현장 상황 변화로 발생. **5~15초** 안에 끝나며, 팀이 정보를 다시 확인하거나 서로 돕는 상황을 만든다.

| 유형 | 내용 |
| --- | --- |
| **동선 방해** | 조사 경로가 잠깐 막히거나 군중 흐름이 바뀌어 돌아가야 함 |
| **장비 방해** | 조사 장비가 밀려나거나 위치가 바뀜, 외계 벌레가 붙어 화면 노이즈 발생 |
| **본부 화면 방해** | CCTV 채널이 바뀌거나 화면 낙서·지도 회전으로 관제 확인 지연 |
| **소통 방해** | 무전 잡음, 말하는 사람 표시 오류, 일시적 무전 차단 |
| **구조형 방해** | 외계 드론이 요원을 끌고 가거나 점액이 발을 묶음 → 다른 요원이 도우면 빠르게 해제 |

- **대응 방식**: 본부 확인, 현장 지원, 후보 재지정, 짧은 장비 사용으로 복구.
- **제한**: 발생 전조와 복구 방법을 둔다. 방해는 **즉시 실패로 이어지지 않으며**, 팀이 후보·단서를 다시 확인하게 만든다.

### 9.5 외계인 콘셉트 개발 기준

- **콘셉트 역할**: 위장·비현실적 방해·이상한 단서를 하나의 설정으로 묶는다. "외계인이라서 그럴 수 있다"고 납득되어야 한다.
- **식별 단서**: 사람처럼 보이지만 복장·소지품·동선·행동·주변 반응 중 일부에서 이상한 흔적. **본부가 말로 설명 가능하고 현장이 확인 가능한 형태**로 설계.
- **방해 방식**: 원인과 대응이 바로 보이는 교란 행동(무전 잡음·CCTV 전환·점액 구속·외계 벌레·짧은 납치).
- **구현 우선순위**: 초기 버전은 외형·소지품·부분 이미지처럼 만들기 쉬운 단서부터 검증. 행동 단서·특수 반응은 이동/관찰 난이도/가독성 확인 후 추가.
- **제한**: 콘셉트가 커지면 추리 집중도가 낮아질 수 있음. 모든 단서·방해는 **후보 찾기·포획 결정 흐름 안에서만** 사용.

### 9.6 포획 보조 도구

> **기준**: 후보 추적·지연·반응 유도·최종 대조를 돕는 **제한형 기능**.

| 도구 | 효과 |
| --- | --- |
| **추적 태그** | 의심 후보에 붙이면 본부 지도에 일정 시간 동선 표시 |
| **CCTV 리와인드** | 놓친 후보의 직전 장면을 되감아 복장·이동 방향 재확인 |
| **구역 봉쇄** | 후보가 출구·통로로 빠지기 직전 통로를 잠시 막음 |
| **유도 방송** | 안내 방송으로 후보의 고개/이동 속도 변화 유도 (주변 NPC도 반응 → 오판 가능성) |
| **긴급 정지** | 주변 NPC를 잠깐 멈춤 (재사용 대기시간 증가) |

### 9.7 공로·칭호·개인 미션 (확장 요소)

> 반복 플레이 동기를 위한 확장 요소. **메인 포획 루프가 안정된 뒤** 추가.

- **공로 기록**: 단서 발견·포획 참여·오포획 방지·본부 지원·탐문 기여 등 라운드별 협동 기여 기록.
- **칭호/외형 보상**: 누적 공로 기반 칭호·배지·외형 보상. **게임 밸런스에는 영향 없음.**
- **개인 미션**: 특정 구역 확인·후보 2명 대조·본부에 단서 공유 등 팀 목표와 충돌하지 않는 행동.
- **개인 미션 보상**: 추가 단서·후보 핀 +1·남은 시간 소폭 증가처럼 **팀에도 이득**이 되는 보상.

## 10. 콘텐츠 & 설계 방향

### 10.1 핵심 콘텐츠 축

| 콘텐츠 축 | 설명 |
| --- | --- |
| **본부 관제** | CCTV·지도·센서 정보 + 새 힌트로 수색 방향 제시 |
| **현장 식별** | 시각 힌트·행동 관찰로 군중 속 후보를 좁힘 |
| **불완전 힌트** | 여러 후보를 남기는 단서 제공 |
| **포획 실행** | 후보 확정 후 현장이 제한시간 내 포획 수행 |
| **방해 이벤트** | 동선·시야·장비·본부 화면에 짧은 방해 발생 |
| **조사 미션** | 현장요원이 짧은 미션으로 새 힌트를 띄움 |
| **힌트 전달** | 본부가 원본을 보고 말로 설명, 현장이 듣고 후보를 좁힘 |

### 10.2 설계 방향

| 항목 | 설계 방향 |
| --- | --- |
| **협동 플레이** | 현장은 조사로 힌트를 열고 본부는 말로 설명. 팀은 설명 차이를 확인하며 후보를 좁힘 |
| **명확한 목표** | 제한시간 내 군중 속 외계인 식별·포획으로 목표 단순화 |
| **반복 플레이** | 힌트 조합·후보 배치·군중 패턴이 매 판 달라짐 |
| **프로토타입 우선순위** | 초기 단서·조사 미션·힌트 전달·후보 탐색·방해·포획 루프부터 검증 |
| **코믹 방해** | 방해는 짧게 발생 후 바로 수습 가능. 이후 위치/단서 확인이 남음 |

## 14. 남은 결정 사항(Open Questions)

- [ ] **본부 정보 정확도** — 본부가 후보·힌트를 어느 정도까지 자세히 볼 수 있는가.
- [ ] **확정 조건** — 포획 후보 결정에 필요한 본부 정보 + 현장 확인 조합.
- [ ] **조사/장비 사용 비용** — 추가 카메라·조사 장비를 의미 있는 선택지로 만들 사용 조건·비용.
- [ ] **군중 반응 강도** — 항의·패닉·시야 차단·이동 방해의 강도.
- [ ] **힌트 갱신 주기** — 추적 템포가 늘어지지 않는 힌트 제공 주기·표시 방식.
- [ ] **혼란도 효과** — 도입 여부를 데모 버전 이후 테스트로 결정.
- [ ] **방해 이벤트 빈도** — 웃긴 빈도 vs 피로감 주는 빈도 구분.
- [ ] **본부 전달 정보량** — 본부가 힌트 원본을 얼마나 자세히 보는가.
- [ ] **조사 미션 길이** — 수색 흐름을 끊지 않는 미션 길이 상한.
- [ ] **힌트 형태** — 그림·도형·부분 이미지·소리 단서가 말 전달 혼선을 만드는지 확인.
- [ ] **초기 단서 난이도** — 첫 단서만으로 후보를 얼마나 넓게 남길지.
- [ ] **방해 이벤트 강도** — 무전·CCTV·이동 방해가 추적 흐름을 지나치게 끊지 않는 선.
- [ ] **외형 커스터마이징 연계** — 이름표 교란이 외형 구분·후보 대조 재미로 이어지는지 확인.
